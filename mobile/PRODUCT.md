# Afterglow mobile

Native recreation of the existing watch-together web app for Android and iOS, backed by the user's watchparty Supabase project. Friends join private rooms by invitation code, share synchronized media, chat, and join an optional room audio/video call. Preserve the existing Watch and Chat navigation, player-first layout, source selector, and charcoal/lavender styling. Desktop-size tablets show player and chat side by side.

Calls require an explicit Join action and support at most four simultaneous participants. Generic web embeds use manual playback when the provider does not expose a control API. AdMob banners sit outside media and call controls and use test IDs by default. No premium promises, sample members, fabricated watch history, or unsupported streaming-service integrations.
